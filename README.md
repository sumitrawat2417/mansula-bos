# ManSula BOS (Business Operating System)

**Formerly known as ManSula Nexus**

ManSula BOS is an all-in-one, offline-first Business Operating System designed specifically for Indian SMEs, cafes, retail stores, and restaurants. It aims to replace traditional notebooks, spreadsheets, and expensive cloud-based POS software with a free, on-device solution.

## Features

- **POS Software:** Lightning-fast order processing, sub-second checkout, barcode scanning, and multi-payment support (UPI, Cash, Card, Udhaar).
- **Inventory Management:** Real-time stock deduction, low-stock alerts, purchase ledgers, and margin analysis.
- **Billing Software:** GST-compliant receipt generation, UPI QR code integration, and Bluetooth thermal printer support.
- **Udhaar Khata (Ledger):** Digital credit system with per-customer profiles, timestamped dispute-proof records, and an overall receivables dashboard.
- **Customer Management (CRM):** Rich customer profiles, lifetime value tracking, order history, VIP tagging, and loyalty building tools.
- **Business Analytics:** On-device computation of gross revenue, net profit tracking, peak hour reports, and per-product margin analysis—without sending any data to external servers.
- **Data Backup:** Complete one-tap backup and restore capabilities (exports `.mnx` snapshot files).

## Technical Overview

- **Offline-First PWA:** Built as a Progressive Web Application (PWA). Once loaded, it runs entirely offline without requiring a continuous internet connection.
- **Privacy-Centric:** Uses browser `IndexedDB` and `localStorage` to securely store all operational business data on the user's device. No business data is uploaded or transmitted to any remote cloud servers.
- **Zero Dependencies:** Pure HTML, CSS, and Vanilla JavaScript for maximum performance and minimal bloat.

## Quick Start

Open `index.html` in any modern web browser to access the application. You can "Install" the application directly from the browser (no App Store or Play Store needed) to use it as a native desktop or mobile app.
